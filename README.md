# LifeGame (인생게임) - Level Up Your Life & Resume ⚔️

> 일상의 퀘스트와 학습을 실시간 RPG 스탯으로 전환하고, 채용 담당자를 위한 포트폴리오 이력서로 변환하는 레트로 8-Bit 라이프 대시보드 웹 애플리케이션입니다.

## 🎮 주요 기능
- **RPG 게임 모드 & 이력서 모드 전환**: 8비트 레트로 픽셀 대시보드와 출력 최적화 PDF 이력서 모드(`RESUME`) 지원
- **6축 레이더 스탯 매트릭스 (HTML5 Canvas)**: 코딩/배포/분석/협업/멘탈/행운 역량 실시간 시각화 및 인터랙티브 툴팁
- **퀘스트 로그 & 보스 던전 (자격증/프로젝트)**: 일일 퀘스트 및 보스 마일스톤 달성, 스크린샷 증빙 업로드 및 인앱 라이트박스 뷰어
- **레트로 8비트 사운드**: Web Audio API 기반 효과음 (점프, 레벨업 팡파르, 보상 획득음 등)
- **로컬 스토리지 데이터 저장**: 브라우저 로컬 스토리지를 통한 진행 상황 영구 저장

## 🚀 실행 방법
별도의 빌드 과정 없이 `index.html` 파일을 브라우저에서 바로 열거나 정적 호스팅(GitHub Pages, Vercel 등)에 배포하여 사용할 수 있습니다.
