> 매일 퀘스트를 깼더니 어느새 완성형 캐릭터가 되어버린 건에 대하여.  
> 2D 픽셀 아트 감성의 직관적인 성장형 블로그 & 실무 이력서 변환 웹 플랫폼입니다.

## 🎮 주요 기능

- **3단 화면 탭 분리**: 대시보드(🎮) / 커스텀 스킬트리 연구소(🌲) / 실무 이력서 뷰(📄)
- **도트 캐릭터 & 프로필 설정**: 전 직무 6대 캐릭터 아키타입(개발, 기획, 디자인, 마케팅, 시스템, 올라운더)과 커스텀 칭호
- **3:4 표준 증명사진 연동**: 채용 담당자 제출용 3:4 규격 증명사진 업로드, 대시보드 서브 프로필 뱃지 및 상단 헤더 프로필 연동
- **채용 담당자용 표준 기술 이력서**: 게임 수치 없이 실제 기술 스택(누적 퀘스트 수, 실무 시간), 프로젝트 로그, 자격증 포맷 제공
- **Cloudflare Pages & KV 기기 간 실시간 동기화**: PC와 모바일 브라우저 간 완벽한 데이터 동기화 지원

## ☁️ Cloudflare Pages & KV 연동 설정 가이드 (PC-모바일 동기화)

THE Life Game은 **Cloudflare Pages Functions**와 **Cloudflare KV**를 통해 복잡한 회원가입 없이도 PC와 모바일 기기 간 데이터를 실시간으로 동기화합니다.

### 1. Cloudflare KV 네임스페이스 생성
1. [Cloudflare 대시보드](https://dash.cloudflare.com/)에 로그인합니다.
2. 좌측 메뉴에서 **Storage & Databases** &rarr; **KV**를 클릭합니다.
3. **[Create a namespace (네임스페이스 생성)]** 버튼을 클릭합니다.
4. 네임스페이스 이름에 `lifegame-kv` (또는 원하는 이름)를 입력하고 **Add**를 누릅니다.

### 2. Cloudflare Pages 프로젝트에 KV 바인딩 연결
1. 좌측 메뉴에서 **Workers & Pages** &rarr; 본인의 Pages 프로젝트(`product-builder-test`)를 선택합니다.
2. 상단 탭에서 **Settings (설정)** &rarr; 좌측 메뉴에서 **Functions (함수)**를 클릭합니다.
3. 스크롤을 내려 **KV namespace bindings (KV 네임스페이스 바인딩)** 항목을 찾습니다.
4. **[Add binding (바인딩 추가)]** 버튼을 클릭합니다:
   - **Variable name (변수 이름)**: `LIFEGAME_KV` ⚠️ *(반드시 대문자로 정확히 입력)*
   - **KV namespace (KV 네임스페이스)**: 1단계에서 생성한 `lifegame-kv` 선택
5. **Save (저장)** 버튼을 클릭합니다.

### 3. 배포 및 실시간 동기화 확인
- 다음 Git 푸시 또는 대시보드 재배포(`Retry deployment`) 시 자동으로 서버리스 함수(`/api/sync`)가 활성화됩니다.
- 사이트 상단 우측 헤더에 🟢 **"동기화됨"** 인디케이터가 표시되면 정상 연동 완료입니다!

## 📱 PC - 모바일 기기 간 연동 방법

1. **기본 단일 사용자 모드 (Default)**:
   - 패스코드를 비워두시면 기본 계정으로 자동 동기화됩니다. PC에서 작성한 퀘스트나 프로필이 모바일 브라우저 접속 시 즉시 동기화됩니다.
2. **개인 패스코드 모드 (Private Passcode)**:
   - 상단 헤더의 **[🔑]** 아이콘을 클릭하여 나만의 고유 패스코드(예: `MY-KEY-777`)를 지정할 수 있습니다.
   - 모바일 브라우저에서도 동일한 패스코드를 입력하거나, **[📋 모바일 연동 링크 복사]** 버튼을 눌러 생성된 주소로 모바일에서 접속하면 둘만의 데이터가 안전하게 실시간 공유됩니다.
3. **수동 동기화**:
   - 상단 헤더의 **[🔄 동기화]** 버튼을 누르면 언제든지 클라우드의 최신 데이터를 즉각 불러올 수 있습니다.
